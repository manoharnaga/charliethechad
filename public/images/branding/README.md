# Branding Assets

Place your site-wide branding images here:

| File | Size | Purpose |
|------|------|---------|
| `logo.png` | Any | Header logo |
| `og-default.png` | 1200×630px | Default social share image |
| `apple-touch-icon.png` | 180×180px | iOS home screen icon |
| `author.png` | 400×400px | Your photo (About page) |
| `default-cover.png` | 1200×630px | Fallback for posts without images |

## Quick Setup

1. Create your images at the sizes above
2. Compress them at [squoosh.app](https://squoosh.app)
3. Drop them in this folder
4. That's it! The site will use them automatically.
