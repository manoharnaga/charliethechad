# Book Cover Images

Place book cover images here.

## Naming Convention
Use the same slug as your book:
- Book: `src/content/books/mindful-money.md`  
- Image: `public/images/books/mindful-money.png`

## Recommended
- Size: 400×600px (2:3 ratio)
- Format: PNG
- Max file size: 150KB

## Usage in Markdown
```yaml
---
title: "My Book"
coverImage: "/images/books/my-book.png"
---
```
